Katrina — Digital Design Portfolio. 
A portfolio website for a digital design professional, built to showcase her artwork and support her job applications.
Live site: https://katrinakhoury.vercel.app/)
Overview;
This site gives a digital designer a clean, professional place to present her work to hiring managers and clients. 
The design follows a minimal, editorial gallery style: full-bleed imagery, a restrained navigation bar, and a hero image 
on the homepage so the artwork stays the focus. 

Features; 
Hero homepage featuring her work front and center
Gallery sections organized by project or category
Resume and contact information
Responsive layout for desktop and mobile
Deployed to a live, shareable link
Built With; 
HTML / CSS / JavaScript, or framework used, e.g., React, Next.js
Hosting platform, e.g., Vercel, Netlify, GitHub Pages
Claude Code (AI-assisted development)

My Role;
I designed and built this site for a client, from design direction through deployment:
Gathered requirements and design references from the client
Organized her artwork, resume, and contact info into the site structure
Built the layout, gallery, and responsive design
Revised the homepage based on feedback (added a hero image to fill empty space)
Deployed the site to a live link
